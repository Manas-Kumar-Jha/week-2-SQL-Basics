SQL-Based Data Analysis Using Superstore Dataset

Objective: Analyze sales data using SQL with filtering, aggregation, and business queries. Steps: 1.Load dataset into a SQL database. 2.Explore table (schema, sample data). 3.Apply WHERE filters (region, category, date, sales). 4.Use GROUP BY for aggregations (sales, quantity, averages). 5.Sort and limit results (top products, top categories). 6.Solve use cases (monthly trends, top customers, duplicates). 7.Validate results (row counts, data quality). Output: SQL script / Notebook + query results + brief insights.

Tools & Technologies
Python
Pandas
MySQL
SQLAlchemy
Jupyter Notebook

Dataset Information

Dataset: Superstore Sales Dataset
Records: 9,995
Columns: 21
Domain: Retail Sales Analysis

Tasks Performed

Imported dataset into MySQL.
Explored table structure and sample records.
Applied filtering using WHERE clauses.
Performed aggregations using GROUP BY.
Sorted and limited results using ORDER BY and LIMIT.
Executed business queries for sales trends, top customers, and product performance.
Validated data quality through row counts and duplicate checks.

Key Insights

The Technology category generated the highest revenue.
The West region recorded the highest sales.
High discounts contributed to several loss-making products.
A small group of customers accounted for a significant portion of revenue.
Monthly sales trends indicated seasonal fluctuations.
Duplicate Order IDs were expected due to multiple products within a single order.
